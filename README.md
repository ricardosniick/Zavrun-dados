# zavrun-dados

Dados **públicos de mapa** usados pelo app ZAVRUN em cidades fora de Goiânia: parques e voltas,
nomes de ruas e bairros (busca) e a rede de ruas para calcular rotas de corrida e de bike no celular.

- Origem: [OpenStreetMap](https://www.openstreetmap.org/copyright) (via [Protomaps](https://protomaps.com)).
  País e estado das cidades: [GeoNames](https://www.geonames.org) (CC BY 4.0).
- Este repositório **não contém** código do app, dados de usuários, localização de pessoas, atividades nem chaves.
- Arquivos: `v1/cities.json` (índice) e `v1/<uf>-<cidade>.json` (um pacote por cidade).
- Gerado automaticamente; não editar à mão.
